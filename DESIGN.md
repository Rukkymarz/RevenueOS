# RevenueOS visual direction

The owner selected warm charcoal, copper and cream on November 11, 2026. Use #1B1917 canvas, #24211E panels, #D99D79 copper, #ECE1D0 cream type and muted sage for success. This replaces the earlier cyan/violet palette. Preserve the AI orb, command composer, grouped navigation, themes, truthful metrics and approval controls.

## Applied references

- VoltAgent/awesome-design-md: Claude guide for warm editorial tones and serif headings; Linear guide for precise typography, restrained panel borders and hierarchy; Stripe guide for tabular financial values and atmospheric light. Adapt principles, never third-party logos, proprietary fonts or marketing claims.
- WorldFlowAI/everything-claude-code: frontend-patterns and verification-loop installed in skills/. Use composition, accessible focus states, lightweight CSS and browser verification. No hooks or external MCP configuration enabled.
- Existing UI UX Pro Max guidance remains in design-system/revenueos/MASTER.md.

Decorative elements are hidden from assistive technology. Respect light theme, reduced motion and small screens. No invented charts or sample customer records.
